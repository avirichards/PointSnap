# PointSnap airline access status

Updated September 5, 2026. This report separates working PointSnap connections, native browser evidence, cached discovery data and documented access requirements. **All-airline native live search is not complete.** Forty-one programs and booking flows are tracked; this is not a claim to have tested every airline worldwide.

## What actually works

Nine scoped sources now supply individual live flight offers in the configured local app: Alaska Atmos, JetBlue TrueBlue, Aeromexico Rewards, Frontier Miles, Ethiopian ShebaMiles, Skywards' easyJet/Jet2 partner portal, and the anonymous American, Delta and Smiles browser connections. ## Wider review and remaining options

The approved plan prioritizes direct anonymous connections, then app-operated anonymous browsers, starting with American. Customers must not need airline connections or a helper installation. Operator-held accounts are a fallback for demonstrated member-access needs; an award-data subscription is outside the plan. Optional hosting/compute must fit within the total $100/month infrastructure ceiling. The [access-options assessment](airline-access-options.md) retains earlier alternatives as historical research. The anonymous browser-service option is verified locally for American, Delta and Smiles. The ordinary-Chrome collector now runs independently of the conversation. Member-session recovery remains unverified.

Finnair's actual Award flight tab was also opened: it asks for a Finnair Plus account before displaying the award form. Copa's newly discovered current anonymous miles booker also reaches verification: its fresh server initialization returns 403, and the normal browser displays a challenge. LATAM's actual published miles-deal link redirects to member login before flight choices. Korean Air's public availability page explicitly uses a daily cached snapshot; its real-time Mileage Booking button opens login. The detailed evidence table below distinguishes these browser findings from documentation-only reviews.

The [Seats.aero public frontend](https://github.com/avirichards/PointSnap/blob/codex/finish-pointsnap/docs/live-data.md#seatsaero-research-using-the-authorized-pro-session) was inspected using the authorized Pro session. It calls Seats.aero's servers; it does not disclose their airline connector backend. Their official [Live Search documentation](https://developers.seats.aero/reference/live-search) requires commercial access. A personal Pro account does not provide that product's live-search API to PointSnap.

The earlier investigation did not exhaust every architecture. A dedicated browser service now produces native American, Delta and Smiles results locally, without customer connections. American required a separately launched ordinary Chrome process; managed-browser launch and profile persistence alone did not reproduce that result. Previous tool-permission and managed-browser failures remain historical evidence, not a current claim that the new path is unavailable. Hosted ordinary Chrome, expanded result completeness and unattended qualification remain open. No paid data service or personal browser session has been substituted.
